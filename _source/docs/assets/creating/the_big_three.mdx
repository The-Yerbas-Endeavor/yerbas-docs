# Root, sub and unique assets

Mainnet v4 wallet operations are restricted below tip height **1,195,400**. See [availability and backup guidance](/docs/wallet/assets/). This wallet safeguard is distinct from consensus validation.

Root assets create a top-level name. Sub-assets create a name below a parent; unique assets identify a unique item under a parent. Parent ownership is required where specified by the RPC. Use `issue` for root/sub-assets and `issueunique` for unique assets; query their help before choosing units, quantities and metadata.

The additional asset fees are 69.420 YERB for a root, 20 YERB for a sub-asset and 0.2 YERB per unique asset. Ordinary transaction fees also apply. Reissuance costs an additional 20 YERB where the asset is reissuable and the wallet has the required owner token.
