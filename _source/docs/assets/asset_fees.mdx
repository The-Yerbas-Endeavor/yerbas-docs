# Asset fees

Mainnet v4 wallet operations are restricted below tip height **1,195,400**. See [availability and backup guidance](/docs/wallet/assets/). This wallet safeguard is distinct from consensus validation.

`GetAssetsFees` specifies the additional asset-operation fee:

| Operation | YERB |
| --- | ---: |
| Root asset | 69.420 |
| Sub-asset | 20 |
| Unique asset | 0.2 per asset |
| Message channel | 4.2 |
| Reissue | 20 |
| Qualifier | 42 |
| Sub-qualifier | 4 |
| Restricted asset | 69.420 |
| Owner / vote / NULL_ADD_QUALIFIER | 0 |

These are additional asset fees; normal transaction fees still apply. Mainnet `AssetsRewardShare(0.8, 0.2, 0.0)` configures smartnode/miner/founder shares in that order. Actual block payment conditions apply, so these shares do not guarantee a payment to an individual operator. The previous guide's 0.004-YERB tag fee and inconsistent qualifier amounts were incorrect for this source.
