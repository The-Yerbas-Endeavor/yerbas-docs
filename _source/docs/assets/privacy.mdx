# Asset privacy

Mainnet v4 wallet operations are restricted below tip height **1,195,400**. See [availability and backup guidance](/docs/wallet/assets/). This wallet safeguard is distinct from consensus validation.

Asset transactions and their on-chain metadata references are public. Referenced files may be stored elsewhere; access control, encryption and file availability are responsibilities of the external storage/application. Do not put private information in an asset name or public metadata. This release does not provide automatic metadata encryption.
