# help

RPC help captured from **Yerbas Core 4.0.1.4** (`f0e2dde`).

Use `./yerbas-cli help help` on your node for help. In the GUI console omit `yerbas-cli`. HTTP examples use mainnet RPC port 15419; network-specific defaults and availability can differ.

```text
help ( "command" ) ("subCommand")

List all commands, or get help for a specified command.

Arguments:
1. "command"     (string, optional) The command to get help on
2. "subCommand"  (string, optional) The subcommand to get help on. Please not that not all subcommands support this at the moment

Result:
"text"     (string) The help text
```
