# bls

RPC help captured from **Yerbas Core 4.0.1.4** (`f0e2dde`).

Use `./yerbas-cli help bls` on your node for help. In the GUI console omit `yerbas-cli`. HTTP examples use mainnet RPC port 15419; network-specific defaults and availability can differ.

```text
bls "command" ...
Set of commands to execute BLS related actions.
To get help on individual commands, use "help bls command".

Arguments:
1. "command"        (string, required) The command to execute

Available commands:
  generate          - Create a BLS secret/public key pair
  fromsecret        - Parse a BLS secret key and return the secret/public key pair
```
