# transfer

RPC help captured from **Yerbas Core 4.0.1.4** (`f0e2dde`).

Use `./yerbas-cli help transfer` on your node for help. In the GUI console omit `yerbas-cli`. HTTP examples use mainnet RPC port 15419; network-specific defaults and availability can differ.

```text
transfer "asset_name" qty "to_address" "message" expire_time "change_address" "asset_change_address"

THIS COMMAND IS NOT YET ACTIVE!
https://github.com/The-Yerbas-Endeavor/yerbas

V4 mainnet wallet policy: asset creation, sending, reissuance, ownership transfers, and asset reward payouts
are locked below tip height 1195400. Receiving/viewing assets and ordinary YERB payments remain available.
Testnet/regtest are unaffected. This is wallet policy, not a consensus restriction on raw transactions.

Transfers a quantity of an owned asset to a given address
Arguments:
1. "asset_name"               (string, required) name of asset
2. "qty"                      (numeric, required) number of assets you want to send to the address
3. "to_address"               (string, required) address to send the asset to
4. "message"                  (string, optional) Once RIP5 is voted in ipfs hash or txid hash to send along with the transfer
5. "expire_time"              (numeric, optional) UTC timestamp of when the message expires
6. "change_address"       (string, optional, default = "") the transactions YERB change will be sent to this address
7. "asset_change_address"     (string, optional, default = "") the transactions Asset change will be sent to this address

Result:
txid[
txid
]

Examples:
> yerbas-cli transfer "ASSET_NAME" 20 "address" "" "QmTqu3Lk3gmTsQVtjU7rYYM37EAW4xNmbuEAp2Mjr4AV7E" 15863654
> yerbas-cli transfer "ASSET_NAME" 20 "address" "" "QmTqu3Lk3gmTsQVtjU7rYYM37EAW4xNmbuEAp2Mjr4AV7E" 15863654
```
