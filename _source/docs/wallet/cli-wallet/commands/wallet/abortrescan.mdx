# abortrescan

RPC help captured from **Yerbas Core 4.0.1.4** (`f0e2dde`).

Use `./yerbas-cli help abortrescan` on your node for help. In the GUI console omit `yerbas-cli`. HTTP examples use mainnet RPC port 15419; network-specific defaults and availability can differ.

```text
abortrescan

Stops current wallet rescan triggered e.g. by an importprivkey call.

Examples:

Import a private key
> yerbas-cli importprivkey "mykey"

Abort the running wallet rescan
> yerbas-cli abortrescan

As a JSON-RPC call
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "abortrescan", "params": [] }' -H 'content-type: text/plain;' http://127.0.0.1:15419/
```
