# getreceivedbyaddress

RPC help captured from **Yerbas Core 4.0.1.4** (`f0e2dde`).

Use `./yerbas-cli help getreceivedbyaddress` on your node for help. In the GUI console omit `yerbas-cli`. HTTP examples use mainnet RPC port 15419; network-specific defaults and availability can differ.

```text
getreceivedbyaddress "address" ( minconf addlocked )

Returns the total amount received by the given address in transactions with at least minconf confirmations.

Arguments:
1. "address"         (string, required) The yerbas address for transactions.
2. minconf             (numeric, optional, default=1) Only include transactions confirmed at least this many times.
3. addlocked           (bool, optional, default=false) Whether to include transactions locked via InstantSend.

Result:
amount   (numeric) The total amount in YERB received at this address.

Examples:

The amount from transactions with at least 1 confirmation
> yerbas-cli getreceivedbyaddress "XwnLY9Tf7Zsef8gMGL2fhWA9ZmMjt4KPwG"

The amount including unconfirmed transactions, zero confirmations
> yerbas-cli getreceivedbyaddress "XwnLY9Tf7Zsef8gMGL2fhWA9ZmMjt4KPwG" 0

The amount with at least 6 confirmations
> yerbas-cli getreceivedbyaddress "XwnLY9Tf7Zsef8gMGL2fhWA9ZmMjt4KPwG" 6

As a json rpc call
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "getreceivedbyaddress", "params": ["XwnLY9Tf7Zsef8gMGL2fhWA9ZmMjt4KPwG", 6] }' -H 'content-type: text/plain;' http://127.0.0.1:15419/
```
