# importelectrumwallet

RPC help captured from **Yerbas Core 4.0.1.4** (`f0e2dde`).

Use `./yerbas-cli help importelectrumwallet` on your node for help. In the GUI console omit `yerbas-cli`. HTTP examples use mainnet RPC port 15419; network-specific defaults and availability can differ.

```text
importelectrumwallet "filename" index

Imports keys from an Electrum wallet export file (.csv or .json)

Arguments:
1. "filename"    (string, required) The Electrum wallet export file, should be in csv or json format
2. index         (numeric, optional, default=0) Rescan the wallet for transactions starting from this block index

Examples:

Import the wallet
> yerbas-cli importelectrumwallet "test.csv"
> yerbas-cli importelectrumwallet "test.json"

Import using the json rpc call
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "importelectrumwallet", "params": ["test.csv"] }' -H 'content-type: text/plain;' http://127.0.0.1:15419/
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "importelectrumwallet", "params": ["test.json"] }' -H 'content-type: text/plain;' http://127.0.0.1:15419/
```
