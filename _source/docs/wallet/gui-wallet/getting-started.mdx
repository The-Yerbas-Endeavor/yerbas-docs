# Getting started with the GUI

[Install and verify Core 4.0.1.4](/docs/wallet/quick-start/), then start the graphical wallet and allow synchronization to finish.

Use Receive to create a receiving address, Send to review and send a transaction, and Transactions to inspect wallet history. Check the address, amount, and fee before confirming a payment.

The Qt 6 **Asset Manager** groups My Assets, Send, Create, Reissue, and Restricted controls. My Assets offers search, balances, metadata/details, and selected-asset sending. Read [asset availability and backups](/docs/wallet/assets/) before using it.

Older screenshots elsewhere in this guide illustrate general workflows; labels and appearance can differ in Qt 6. The release does not implement arbitrary smart contracts.
