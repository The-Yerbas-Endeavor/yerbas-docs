# GUI installation

Follow the [4.0.1.4 download and upgrade guide](/docs/wallet/quick-start/) to select and verify your archive.

1. Extract into a new application folder.
2. On Windows run `yerbas-build/yerbas-qt.exe`; on macOS open `yerbas-build/Yerbas-Qt.app`; on Linux run `./yerbas-qt` inside `yerbas-build/`.
3. Let the wallet synchronize. The GUI includes the node; do not start `yerbasd` against the same data directory.
4. Encrypt and back up the complete wallet using its wallet menu. Store the backup separately from the computer.

The release provides archives, not setup installers. Platform-specific runtime requirements are listed in the download guide.
