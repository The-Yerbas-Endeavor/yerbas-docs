# Smartnodes

Yerbas Core 4.0.1.4 uses deterministic smartnodes for quorum services, including InstantSend and ChainLocks, and for PrivateSend coordination. Registration, eligible collateral, network connectivity, and quorum participation matter; registration alone does not guarantee payments or service availability.

This release does **not** execute arbitrary smart contracts. Historical whitepapers describe proposals, not implemented release features.

Start with [requirements](/docs/smartnodes/requirements/), [manual setup](/docs/smartnodes/installation/manualsetup/), and [recovery behavior](/docs/smartnodes/recovery/).
