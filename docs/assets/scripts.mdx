# Asset scripts

Mainnet v4 wallet operations are restricted below tip height **1,195,400**. See [availability and backup guidance](/docs/wallet/assets/). This wallet safeguard is distinct from consensus validation.

Asset scripts carry serialized asset operations. Use the pinned implementation for byte-level encoding and validation; do not copy historical explorer examples as a transaction template.

## Chain parsing note {#chain_parsing_note}

Parse actual scripts and transaction structure rather than inferring asset type from an explorer label or wallet display. Consult the script constructors/decoders in `assets.cpp`, the asset structures in `assets.h`, and `script.cpp`. Wallet policy restrictions do not replace consensus validation of raw transactions.
