Qualifiers and restricted assets

Mainnet v4 wallet operations are restricted below tip height 1,195,400. See availability and backup guidance. This wallet safeguard is distinct from consensus validation.

Qualifiers and sub-qualifiers use # names; restricted assets use $ names and verifier rules. Qualifier tags can determine whether an address is permitted to receive a restricted asset. Restricted controls require the relevant administrative authority.

Inspect issuequalifierasset, issuerestrictedasset, addtagtoaddress, removetagfromaddress, and the freeze/unfreeze command help before constructing a transaction. These operations can affect transfers and require review.

See fees: qualifier issuance is 42 YERB, sub-qualifier issuance 4 YERB and restricted issuance 69.420 YERB. The asset-fee function assigns zero to NULL_ADD_QUALIFIER; this does not waive ordinary transaction fees.
