# What is an asset?

Mainnet v4 wallet operations are restricted below tip height **1,195,400**. See [availability and backup guidance](/docs/wallet/assets/). This wallet safeguard is distinct from consensus validation.

Native assets have names, quantities, divisibility, and optional metadata. Issuance, transfer and reissuance are validated by Core. An asset name or metadata reference does not independently establish the identity of its issuer, authenticity of an artwork, or ownership of an off-chain item. Native assets do not execute arbitrary smart contracts.
