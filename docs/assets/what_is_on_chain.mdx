# On-chain asset data

Mainnet v4 wallet operations are restricted below tip height **1,195,400**. See [availability and backup guidance](/docs/wallet/assets/). This wallet safeguard is distinct from consensus validation.

Core validates asset operations in transaction scripts and maintains asset state/indexes. Names, quantities, units, reissuability and supported metadata fields are represented by asset structures and their serialization.

An IPFS reference is not the referenced file. Keep external metadata available and backed up separately. A wallet backup does not automatically preserve externally hosted content.
