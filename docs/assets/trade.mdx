# Trading assets

Mainnet v4 wallet operations are restricted below tip height **1,195,400**. See [availability and backup guidance](/docs/wallet/assets/). This wallet safeguard is distinct from consensus validation.

This Core release does not establish or endorse an asset marketplace. Sending an asset is a blockchain transaction, not proof of a marketplace listing or an enforceable off-chain exchange. Verify counterparties and asset identity separately.
