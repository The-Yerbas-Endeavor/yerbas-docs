# getbestchainlock

RPC help captured from **Yerbas Core 4.0.1.4** (`f0e2dde`).

Use `./yerbas-cli help getbestchainlock` on your node for help. In the GUI console omit `yerbas-cli`. HTTP examples use mainnet RPC port 15419; network-specific defaults and availability can differ.

```text
getbestchainlock

Returns the block hash of the best chainlock. Throws an error if there is no known chainlock yet.

Result:
{
  "blockhash" : "hash",      (string) The block hash hex encoded
  "height" : n,              (numeric) The block height or index
  "known_block" : true|false (boolean) True if the block is known by our node
}

Examples:
> yerbas-cli getbestchainlock
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "getbestchainlock", "params": [] }' -H 'content-type: text/plain;' http://127.0.0.1:15419/
```
