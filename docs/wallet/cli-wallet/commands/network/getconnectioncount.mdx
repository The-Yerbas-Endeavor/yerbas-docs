RPC help captured from **Yerbas Core 4.0.1.4** (`f0e2dde`).

Use `./yerbas-cli help getconnectioncount` on your node for help. In the GUI console omit `yerbas-cli`. HTTP examples use mainnet RPC port 15419; network-specific defaults and availability can differ.

getconnectioncount

Returns the number of connections to other nodes.

n          (numeric) The connection count
