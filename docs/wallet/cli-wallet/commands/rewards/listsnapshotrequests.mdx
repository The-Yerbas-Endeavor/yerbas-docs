# listsnapshotrequests

RPC help captured from **Yerbas Core 4.0.1.4** (`f0e2dde`).

Use `./yerbas-cli help listsnapshotrequests` on your node for help. In the GUI console omit `yerbas-cli`. HTTP examples use mainnet RPC port 15419; network-specific defaults and availability can differ.

```text
listsnapshotrequests ["asset_name" [block_height]]

List snapshot request details.

Arguments:
asset_name: (string, optional) List only requests for a specific asset (default is "" for ALL)
block_height: (number, optional) List only requests for a particular block height (default is 0 for ALL)

Result:
[
  {
    asset_name: (string),
    block_height: (number)
  }
]

Examples:
> yerbas-cli listsnapshotrequests
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "listsnapshotrequests", "params": ["TRONCO" 345333] }' -H 'content-type: text/plain;' http://127.0.0.1:15419/
```
