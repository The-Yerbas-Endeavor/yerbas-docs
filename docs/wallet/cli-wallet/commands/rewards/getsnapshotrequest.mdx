# getsnapshotrequest

RPC help captured from **Yerbas Core 4.0.1.4** (`f0e2dde`).

Use `./yerbas-cli help getsnapshotrequest` on your node for help. In the GUI console omit `yerbas-cli`. HTTP examples use mainnet RPC port 15419; network-specific defaults and availability can differ.

```text
getsnapshotrequest "asset_name" block_height

Retrieves the specified snapshot request details.

Arguments:
1. "asset_name"              (string, required) The asset name for which the snapshot will be taken
2. "block_height"            (number, required) The block height at which the snapshot will be take

Result:
{
  asset_name: (string),
  block_height: (number),
}

Examples:
> yerbas-cli getsnapshotrequest "TRONCO" 12345
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "getsnapshotrequest", "params": ["PHATSTACKS" 34987] }' -H 'content-type: text/plain;' http://127.0.0.1:15419/
```
