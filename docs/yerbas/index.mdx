# What is Yerbas?

Yerbas is a proof-of-work blockchain using GhostRider, with native assets and a deterministic smartnode network. Core **4.0.1.4** provides a Qt 6 wallet and command-line tools.

This release supports native assets and wallet asset management; it does not implement arbitrary smart contracts. Historical papers describe design proposals and must not be treated as the current consensus specification.

Read [downloads and upgrades](/docs/wallet/quick-start/), [assets](/docs/wallet/assets/), [smartnodes](/docs/smartnodes/), and [current consensus facts](/docs/yerbas/consensus/).

PrivateSend coordinates mixing through smartnodes. See [PrivateSend](/docs/wallet/privatesend/) for the workflow; availability depends on network participation.
