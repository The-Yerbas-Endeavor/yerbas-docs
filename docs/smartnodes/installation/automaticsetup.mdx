# Automatic setup

Older community installers and update scripts are not validated by this 4.0.1.4 documentation update. They may use obsolete downloads, ports or collateral assumptions.

Use the [manual setup guide](/docs/smartnodes/installation/manualsetup/) and [verified release archives](/docs/wallet/quick-start/). If using an external installer, inspect its source, release selection, checksum checks, paths, configuration and service behavior before running it. Do not pipe an unreviewed remote script directly into a shell.
